You control this session here. Nothing connects until you choose Start sharing or Connect.

Local network mode · Private approval · No discovery

The existing abox.tools pairing service introduces the browsers. It sees their IP addresses, share code and connection messages. Text and file contents travel directly between the browsers.

No public STUN server or TURN relay is used. Host-only connections work best on the same Wi-Fi or Ethernet; VPNs, firewalls and browser policy can change which routes are available. Keep both pages open.

Up to 50,000 characters and 200,000 UTF-8 bytes. Text is shown as plain text.

Up to 16 files, 128 MiB each and 256 MiB combined. Readers see the names and sizes after you approve them.
